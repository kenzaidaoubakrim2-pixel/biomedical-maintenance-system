# Maintenance - Preventive & Corrective

## Overview
This folder contains all maintenance procedures and schedules.

## Maintenance Types
- **Preventive Maintenance** - Scheduled maintenance to prevent failures
- **Corrective Maintenance** - Emergency repairs and restoration

## Contents
- `Maintenance_Plan_Annual.xlsx` - Annual maintenance schedule
- `Preventive_Maintenance_Procedure.md` - PM procedures
- `Corrective_Maintenance_Procedure.md` - Corrective procedures
- `Intervention_Report_Template.xlsx` - Standardized intervention form
- `Maintenance_Schedule_20_Equipment.xlsx` - Detailed schedule for all 80 equipment

## Key Metrics
- **MTTR** (Mean Time To Repair) - Average repair time
- **MTBF** (Mean Time Between Failures) - Equipment reliability
- **Preventive Task Completion Rate** - Target > 95%
- **Equipment Availability** - Target > 98% for critical equipment
