# Outils - Automation Scripts & Dashboards

## Overview
This folder contains Python scripts, dashboards, and automation tools.

## Contents

### Scripts (`Automation_Scripts/`)
- `Generate_Reports.py` - Automated report generation
- `KPI_Analysis.py` - KPI calculations and analysis
- `Risk_Ranking.py` - Automatic risk ranking

### Dashboards (`Dashboards/`)
- `Dashboard_Index.html` - Main dashboard entry point
- `Performance_Dashboard.js` - Real-time performance metrics
- `Risk_Dashboard.js` - Risk monitoring dashboard

### Templates (`Templates/`)
- `Email_Alert_Template.md` - Alert notification format
- `Meeting_Minutes_Template.md` - Meeting documentation

## Features
- Automated MTTR/MTBF calculation
- Real-time KPI updates
- Risk level monitoring
- Report generation
