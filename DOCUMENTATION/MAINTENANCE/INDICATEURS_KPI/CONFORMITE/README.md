# Conformité - Compliance & Continuous Improvement

## Overview
This folder contains non-conformity registers, CAPA tracking, and management reviews.

## Process
1. **Identify** - Detect non-conformities through audit or operations
2. **Register** - Document in Non-Conformity Register
3. **Analyze** - Root cause analysis
4. **Correct** - Implement corrective actions (CAPA)
5. **Verify** - Confirm effectiveness
6. **Review** - Management review and follow-up

## Contents
- `Non_Conformity_Register.xlsx` - All non-conformities
- `CAPA_Register.xlsx` - Corrective and preventive actions
- `CAPA_Process.md` - CAPA procedure
- `Management_Review_Template.md` - Management review meeting template

## CAPA Tracking
- **Open** - Not yet closed
- **In Progress** - Being implemented
- **Closed** - Completed and verified
- **Target Closure Rate** - > 90%
