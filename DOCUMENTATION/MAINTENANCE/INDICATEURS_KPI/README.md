# Indicateurs KPI - Key Performance Indicators

## Overview
This folder contains KPI definitions, dashboards, and calculation tools.

## Key Performance Indicators

| KPI | Formula | Target |
|-----|---------|--------|
| Preventive Completion Rate | Completed / Planned × 100 | > 95% |
| MTTR | Total repair time / Number of failures | Minimize |
| MTBF | Operating time / Number of failures | Maximize |
| Equipment Availability | Available time / Required time × 100 | > 98% |
| Recurrence Rate | Repeated failures / Total failures × 100 | < 10% |
| Document Compliance | Compliant files / Audited files × 100 | > 95% |
| CAPA Closure Rate | Closed CAPA / Open CAPA × 100 | > 90% |
| Client Satisfaction | Score obtained / Max score × 100 | > 85% |

- `MTTR_MTBF_Calculator.py` - Python calculator
