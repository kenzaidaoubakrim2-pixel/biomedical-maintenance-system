# Audit - Compliance and Verification

## Overview
This folder contains all audit-related documents and templates for MIAO-MB compliance.

## Audit Axes
1. **Organization and Governance** - Roles, planning, competencies, outsourcing
2. **Document Management** - Procedures, intervention records, document control
3. **Maintenance Performance** - Preventive tasks, corrective actions, availability
4. **Risk Management** - Equipment criticality, hazard identification, controls
5. **Client and Continuous Improvement** - Satisfaction, non-conformities, CAPA

## Contents
- `Integrated_Audit_Grid.xlsx` - Master audit checklist
- `Audit_Internal_Plan.md` - Annual audit schedule
- `Audit_Report_Template.md` - Audit report format
- `Audit_Checklist_ISO_Compliant.md` - Detailed checklist

## Scoring System
- **0** = Non-existent requirement
- **1** = Partially defined
- **2** = Applied but not optimized
- **3** = Controlled and improved
