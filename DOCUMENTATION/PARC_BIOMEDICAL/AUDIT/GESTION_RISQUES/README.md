# Gestion des Risques - Risk Management (ISO 14971)

## Overview
This folder implements ISO 14971 risk management methodology for biomedical equipment.

## Risk Management Process
1. **Hazard Identification** - Identify potential dangers
2. **Risk Estimation** - Assess severity, probability, detectability
3. **Risk Evaluation** - Determine acceptability
4. **Risk Control** - Implement mitigation measures
5. **Residual Risk Assessment** - Verify effectiveness
6. **Post-Implementation Monitoring** - Ongoing surveillance
